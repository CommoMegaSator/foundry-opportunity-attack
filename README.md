# Opportunity Attack Reactions (Foundry VTT v13/v14, dnd5e + Midi QOL)

Prompts a reaction attack when a hostile creature leaves a combatant's reach. Requires `socketlib` and `midi-qol`.
Exemptions: the Disengage status, flag `flags.opportunity-attack.noProvoke` on the actor/effect, Flyby items, teleports (unless enabled in settings).
